# 模型如何读取报告并分析

## 证据顺序

1. 下载或读取用户指定的这一次检查。保留原 DICOM 字节，技术检查使用 `inspect`，不调用 `tools/mutate.py` 改动原件。
2. 用户要解释报告时读取报告的影像所见、诊断结论。微影 `report.json` 只摘取这两个正文，但正文仍可能有姓名，不能视为匿名文件。
3. 将“报告直接陈述”“术语的一般解释”“需要结合症状由医生判断”写清楚。可引用少量原文帮助用户核对。若文字矛盾或 OCR 有误，保留不确定性。
4. 若请求涉及原片观察，先核对完整序列、方向、空间位置、窗宽窗位、像素模态变换及是否为定位像/曲线。抽样图或 MP4 不能证明完整检查正常，也不能根据缺少某个序列猜测病变。
5. 只有在回答相关医学问题时，检索可信医学来源补充知识；查询用去身份化的医学术语。临床决策需医生结合病史和完整检查，不用本下载工具给出确定诊断或自行用药方案。

## 推荐回答内容

- 已获得哪些资料：报告文字/影像/仅截图；检查完整性证据是什么。
- 报告原文的主要结论，以及每项术语的通俗解释。
- 资料无法回答的部分，必要时提出与问题直接相关的症状/时间问题。
- 可带给医生核对的具体问题，不生成未经报告支持的“诊断”。

无文本时不要把 SeriesDescription 当报告。下载工具不内置 OCR、图像诊断或临床分级模型。如果宿主有额外分析工具，仍须遵守用户授权和该工具的数据传输范围。
